# Synthetic Data Specialist

## Role Summary

A Synthetic Data Specialist creates, evaluates, governs, and documents artificial datasets used for model training, testing, privacy protection, simulation, or edge-case coverage.

## Why This Role Is Emerging Now

AI teams need data that is useful, safe, representative, and available. Synthetic data can help with privacy constraints, rare scenarios, testing, and simulation, but only if quality and risk are managed carefully.

## Maturity

- Status: Emerging
- Confidence: Medium
- Source signal: Specialist synthetic-data work is clearly hired for, but current titles cluster around engineering and research rather than one stable specialist title.

## Core Responsibilities

- Generate synthetic datasets for defined use cases.
- Evaluate fidelity, utility, bias, and leakage risk.
- Document generation methods and limitations.
- Work with legal, privacy, security, and data teams.
- Maintain dataset versioning and approval records.

## Common Tools

- synthetic data generation platforms
- data quality tools
- privacy testing tools
- notebooks and data pipelines
- simulation environments
- model evaluation tools

## Required Skills

- data science
- statistics
- privacy and data protection literacy
- model evaluation
- documentation
- domain understanding

## Adjacent Existing Roles

## What This Role Is Not

- Not fake data for demos only.
- Not a guaranteed privacy solution.
- Not useful without evaluation against the target task.

## Example Job Titles

- Synthetic Data Specialist
- Synthetic Data Scientist
- Privacy-Preserving Data Specialist

- AI Data Generation Specialist

## Example Work Outputs

- synthetic dataset
- generation method note
- utility and fidelity report
- privacy leakage assessment
- bias and coverage analysis
- dataset card

## Risks and Failure Modes

- Synthetic data preserves private information.
- Data looks realistic but fails the target task.
- Bias is amplified or hidden.
- Downstream teams misunderstand limitations.
