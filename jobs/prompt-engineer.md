# Prompt Engineer

## Role Summary

A Prompt Engineer designs, tests, documents, and improves instructions and interaction patterns for language-model systems. In stronger versions of the role, prompt work is connected to evaluation, retrieval, product behaviour, and human review.

## Why This Role Is Emerging Now

Language models made natural-language instructions part of the production surface. Early demand focused on prompt writing. The role is now formalising into a broader skill set around model behaviour, workflow design, evaluation, and AI product quality.

## Maturity

- Status: Formalising
- Confidence: High
- Source signal: Multiple current exact-title postings, with responsibilities increasingly connected to evaluation, engineering, and workflows.

## Core Responsibilities

- Create and maintain prompt patterns for repeated use cases.
- Test prompts against expected and edge-case inputs.
- Document model behaviour and known failure modes.
- Work with subject-matter experts to encode task context.
- Pair prompts with evaluation rubrics and review workflows.

## Common Tools

- ChatGPT, Claude, Gemini, or enterprise LLM tools
- prompt-management tools
- eval harnesses
- retrieval systems
- version control
- product analytics and tracing tools

## Required Skills

- clear writing
- task decomposition
- model behaviour literacy
- evaluation design
- domain understanding
- structured testing

## What This Role Is Not

- Not magic wording.
- Not a replacement for domain expertise.
- Not sufficient for production AI quality without evaluation and monitoring.

## Example Work Outputs

- prompt library
- system-prompt specification
- prompt test set
- model behaviour notes
- human-review checklist
- prompt change log

## Risks and Failure Modes

- Optimising examples instead of real tasks.
- Treating prompts as unversioned personal craft.
- Shipping prompt changes without regression tests.
- Ignoring data, retrieval, policy, and user-experience constraints.
