# Emerging Job Playbooks

The catalogue profiles define roles. Playbooks go deeper for roles with enough public signal.

Do not create a playbook for every plausible title. Create one when the role is useful enough that a professional, hiring manager, or L&D team needs a practical operating guide.

## Playbook Standard

Each playbook should include:

- first 30 days in the role
- key decisions owned
- stakeholders
- operating rhythm
- metrics that matter
- starter toolkit
- interview questions
- portfolio or project examples
- hiring red flags
- how the role changes by company size

## First Playbook Candidates

- AI Governance Lead
- AI Evaluation Specialist
- AI Transformation Manager

## Evidence Rule

A playbook needs at least two public signals or one strong public signal plus a clear adjacent-role pattern. If the evidence is weaker than that, keep it as a role profile only.
